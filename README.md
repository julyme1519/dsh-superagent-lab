# dsh-superagent-lab

A playground for testing the dsh-superagent research prototype.

Use this repository to exercise the workflow from an authorized change request to a human-reviewed pull request.

## Operating policy

- GitHub agent account and authorized requester: `julyme1519`.
- Pull requests are reviewed and merged by a person; auto-merge is disabled.
- Proactive work starts in observe-only mode.
- The agent should act only on authorized requests and keep changes reviewable.

This repository is a test environment, not a production deployment.
